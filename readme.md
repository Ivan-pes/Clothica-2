# Clothica

Онлайн-магазин одягу. Фінальний командний проєкт GoIT.

## Структура

```text
backend/    API: Node.js, Express, MongoDB
frontend/   Сайт: Next.js
```

## Запуск бекенду

```bash
cd backend
npm install
cp .env.template .env
npm run dev
```

Значення змінних для `.env` можна отримати у тімліда.
